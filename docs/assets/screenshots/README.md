## Placeholders incluídos

O repositório inclui arquivos `.svg` como preview até você adicionar os prints reais.

**Para publicar suas capturas de produção:**

1. Tire screenshots do dashboard em http://&lt;seu-servidor&gt;:8080
2. Salve como PNG (recomendado) com os nomes acima, ex.: `01-dashboard-frota.png`
3. No [README.md](../../README.md), troque `.svg` por `.png` nos links das imagens
4. Opcional: remova os `.svg` após substituir

## Dicas antes de publicar

- Resolução: 1920×1080 ou 1440×900
- **Oculte dados sensíveis:** senhas, e-mails reais, IPs internos, hostnames
- Desfoque credenciais nos formulários de cadastro TI
- Formato: PNG ou WebP
- As imagens nesta pasta **são versionadas** no Git
